# Cartucho — arcade retrô

Página de entrada do site com um cubo mágico jogável em Three.js.
Arquivo único (`index.html`), sem dependências externas além das fontes do Google.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `cartucho-arcade`), público.
2. Envie os arquivos desta pasta (`index.html`, `.nojekyll`, `README.md`).
3. No repositório: **Settings → Pages → Build and deployment**.
4. Em **Source**, escolha **Deploy from a branch**; em **Branch**, escolha `main` e pasta `/ (root)`. Salve.
5. Aguarde 1–2 minutos. O site ficará em:
   `https://SEU-USUARIO.github.io/cartucho-arcade/`

## Controles

- Arraste uma face do cubo para girar a camada.
- Arraste o fundo para girar o cubo inteiro.
- **Embaralhar** e **Resetar** no rodapé.
